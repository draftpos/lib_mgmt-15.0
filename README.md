### Let’s have a look at features of the Library Management

#### ➤ Library Management Information
* The stock of books can be easily managed.
* If you become an employee, you automatically become a customer.
* If you check "Is Member" in the customer, the library automatically becomes a library member.
* You can go to the member's profile, click on the "membership" button, and take the membership

* If you set as many "Allow Days" in the library settings, So when you buy the book, the date will come automatically.
* If you miss the book return date, then "Overdue Penalty (In Days)", "Penalty Amount", and "Penalty Total Amount" will automatically appear, and a new penalty invoice will be generated.
